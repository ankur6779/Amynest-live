## Top 5 highest-ROI improvements (evidence-ranked)

### 1. Deploy stabilization build to production (P0 — enables all other fixes)
**Evidence:** Render services `autoDeploy: no`; Phase 5 events missing; Jul 3 Android `log-client-error` 500s match pre-Phase-3 bug class.  
**Impact:** Unlocks crash fixes, API hardening, activation paywall bypass, resume UX.  
**Action:** Manual deploy `main` @ `053fb57a4` to backend + static site.

### 2. Close onboarding finish → first routine gap (P0 activation)
**Evidence:** Jul 3: 5 `finish_clicked`, 1 `routine_generated`; screen views 22 onboarding vs 4 generate.  
**Impact:** Directly addresses ~90% registered-never-routine baseline; highest leverage retention input.  
**Action:** Post-`finish_success`, auto-route to `/routines/generate` with child pre-selected (measure `navigation` to generate within 5 min).

### 3. Fix Android `log-client-error` 500 for production WebView (P0 observability)
**Evidence:** 8+ consecutive 500s Jul 3 from real Play Store UA; errors not reaching DB.  
**Impact:** Restores crash/intelligence pipeline for largest mobile surface; without it, crash metrics undercount.  
**Action:** Deploy Phase 3 `client-logs` hardening; verify single Android session logs successfully.

### 4. Defer paywall until after first `routine_generated` (P0 conversion timing)
**Evidence:** Jul 3 paywall users (3) > routine generators (1); historical 92% paywall CTA drop; Phase 5 gate not live.  
**Impact:** Improves trial→paid by showing value first; avoids blocking activation.  
**Action:** Deploy Phase 5 `activation-gate`; monitor `paywall_deferred_activation` vs `routine_generated`.

### 5. Instrument routine completion loop on dashboard return (P1 retention)
**Evidence:** 1 `routine_item_completed` vs 4 `routine_viewed` in 2 days; DAU −24% with low generate volume.  
**Impact:** Users who start routines but don't finish are lost next day — resume banner (Phase 5) addresses this once deployed.  
**Action:** Deploy + track `activation_resume` navigation; target >15% CTR on partial routines.
