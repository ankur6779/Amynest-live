# BUYER CLOSING SEQUENCE

**Date:** 24 September 2026  
**Not executed. Phases are a checklist order only.**

## PHASE 0 — PRE-CLOSING

- Legal scope: Path A vs B elected  
- Asset schedule A–E reviewed (`TRANSACTION_ASSET_SCHEDULE.md`)  
- Patent **INCLUDE** or **EXCLUDE** checked  
- Ownership evidence: Play/ASC enrollment, registrar, cloud logins (screenshots offline)  
- Buyer creates: GitHub org, Play + Apple Developer, GCP org, CF, RC, Ads MCC, mailbox  
- Keystore / iOS / Birth Sky / secret **escrow packed** (still founder-held until Phase 1)  
- Encrypted DB dump created (owner)  
- This data-room package complete  

## PHASE 1 — CLOSING

- Execute assignment / bill of sale (counsel)  
- Deliver git transfer **or** admin invite  
- Start vendor transfers / invitations (do not revoke founder yet)  
- Hand escrow media (keystore, dumps, secret list)  
- Source handover: buyer clone of transferred repo  

## PHASE 2 — BUYER CONTROL

- GitHub Owner = buyer  
- Cloud: Coolify, Hetzner, CF, GCP/GCS/Firebase  
- Domain/DNS (after test TXT)  
- Stores (when vendors complete)  
- Billing (RC invite)  
- Analytics/Ads admin  
- Email MX + `ADMIN_ALERT_EMAIL`  

## PHASE 3 — VERIFICATION

- Build web/api on buyer machine  
- Deploy to **staging / scratch**, not a reckless prod flip  
- Database restore + R/W + worker + audio smokes  
- Signed AAB + signed iOS RC (do not submit until accepted)  
- DNS/SSL/mail checks  
- RC webhook 2xx  
- Analytics hit in buyer properties  

## PHASE 4 — ACCEPTANCE

- Founder access removed **only after** gates in `FINAL_ACCEPTANCE_GATES.md`  
- Buyer signs acceptance  
- Final handover record dated  

Do not skip to Phase 4 while G1–G16 are OPEN.
