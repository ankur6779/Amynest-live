# APP STORE RELEASE (shared)

Both stores use package / bundle `com.amynest.app`. Billing is mediated by RevenueCat (`premium`).

## Before any store upload

1. Confirm you are shipping the **correct native tree** (iOS Capacitor vs Android **`android/` WebView**).
2. Bump version in that tree only.
3. Confirm RC offerings match live products.
4. Do **not** claim the product is “patented.” Allowed wording if counsel agrees: “Indian Patent Application No. 202611059355 filed” or “Patent pending” **only if** publication/pending status supports it. Form 9 was **not published** as of this audit.
5. Do **not** claim “12,000+ parents” — **unverified and contradicted** by 231 RC 28-day actives.

## Transfer

Apple and Google transfers are **multi-week** and founder-gated. Start on signing day. See `ACCOUNT_TRANSFER.md`.
