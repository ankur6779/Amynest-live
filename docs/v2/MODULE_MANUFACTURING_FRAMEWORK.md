## Mission

Create the permanent manufacturing framework that **every** AmyNest destination must follow:

Infant Care · Speech Coach · Nutrition · Health Lab · Grow · Birth Sky · Ask Amy · Emotional Support · Guidance · Presence · Story · Talking Amy · Curiosity · Make · PTM · Life Skills · and every future module.

---

## Goal (absolute)

| Forbidden feeling | Required feeling |
|---|---|
| A feature page | Another room in the same home |
| A SaaS tool | Continued companionship |
| A dashboard | Quiet care / help / understanding / presence |
| A marketplace | One calm next step |
| A separate application | Same house · same light · same voice |

> Opening a destination must never feel like opening another app.

---

## Universe stack (do not invert)

```text
Welcome · Signup · Child Discovery · Today Home
              ↓
        Parent Hub (four rooms)
              ↓
     Destination module (this contract)
              ↓
           Life / Home
```

Modules inherit the home.  
Modules do not invent a new brand, material planet, or emotional dialect.

**Reuse Before Rewrite** remains absolute for business logic, APIs, DB, entitlements, RevenueCat.

Manufacturing changes **experience continuity** — not product identity paperwork.

# 1. Manufacturing contract (12 laws)

Every module must specify and pass the following.

---

### 1. Entry — transition from Parent Hub

| Law | Rule |
|---|---|
| E1 | Enter from a **quiet path** inside a room — never from a mall tile grid as product truth |
| E2 | Transition must feel like **walking into an adjoining room**, not launching an app |
| E3 | Prefer deepen-in-place (Hub quiet slot) when the task can complete without a full route |
| E4 | If a route is required, the first frame of the route must **continue** room light/materials — not hard-cut to SaaS chrome |
| E5 | Pack 5 quiet-module law remains permanent for Hub opens (`PREMIUM_VOICE`, no Try Free shelf) |
| E6 | No marketing hero, patent strip, XP pulse, or unlock theatre on entry |

**Pass test:** Parent cannot tell they “left the house.”

---

### 2. Opening — first emotional impression (≤3 seconds)

| Law | Rule |
|---|---|
| O1 | First pixels answer the room intention (Help / Understand / Care / Moments) |
| O2 | One human sentence before any tool chrome |
| O3 | No feature catalogue as first impression |
| O4 | No “dashboard summary” as first impression |
| O5 | Child name may appear; scores / levels / coins may not |

**Pass test:** Tired parent knows why they are here in one breath.

---

### 3. Hero — photography · living materials · illustration

| Priority | When allowed |
|---|---|
| **1. FE photography language** (`/experience/r1/` family or same camera/light grammar) | Default for room entry and module opening |
| **2. Living materials** (FE shell: ambient, wash, breath, glass spill) | Always preferred over purple SaaS glass |
| **3. Illustration** | Only when photography cannot carry the act — never as marketplace wattage |
| **4. Emoji grids** | Forbidden as opening hero; rare as micro-affordance after value, never as storefront |

| Law | Rule |
|---|---|
| H1 | Same light family as Welcome / Discovery / Today Home / Parent Hub rooms |
| H2 | No neon game universe as default (Talking Amy debt must resolve to home calm) |
| H3 | No parallel cinematic brand that denies FE home (Birth Sky may be a “wing” only if Founder explicitly authorizes wing grammar — still same calm/voice) |
| H4 | Hero supports the act — never sells the SKU |

---

### 4. Typography — hierarchy · breath · rhythm

| Law | Rule |
|---|---|
| T1 | One primary question or title; one supporting line; then content |
| T2 | Quicksand / sanctuary reading rhythm consistent with Hub rooms |
| T3 | No uppercase marketing shout (PRO · UNLOCK · NEW · LIMITED) |
| T4 | Breathing room > density; if denser than Hub quiet paths, fail |
| T5 | Numbers that score the parent are forbidden; numbers that help care (oz, minutes) are allowed |

---

### 5. Materials — glass · elevation · radius · light · shadow

| Law | Rule |
|---|---|
| M1 | One material system: FE / sanctuary night light — warm sand edge, restrained glass |
| M2 | Forbidden as module default: purple/pink galaxy wash, violet unlock pills, edtech neon, sparkle FOMO |
| M3 | Radius/elevation match Parent Hub living room + FE shell — not a third planet |
| M4 | Shadows serve depth, not celebration |
| M5 | Hub `lz-glass` / illustration shelf may be subordinated or retired per module manufacturing — never reintroduced as law |

**Allowlist:** Welcome · Discovery · Today Home · Parent Hub rooms materials.  
**Everything else is debt.**

---

### 6. Navigation — back · exit · Home

| Law | Rule |
|---|---|
| N1 | Back returns to the **room path** (or Hub doors) — never orphaned |
| N2 | Exit Law: after a meaningful act, offer return to **life / Today Home** |
| N3 | “Back to Today Home” remains available without hunting |
| N4 | No dead controls; no no-op learning CTAs |
| N5 | Deep links resolve to room + path safely (Production Safety) |
| N6 | Leaving a module must feel like closing a door in the house — not force-quitting an app |

---

### 7. Premium — how it appears · how it NEVER appears

| Appears as | Never appears as |
|---|---|
| `PREMIUM_VOICE.invitation` | Unlock / Try Free / Explore Free storefront |
| `Continue with AmyNest` | Violet lock pills · FOMO · urgency · guilt |
| Continuity after felt value | Paywall before first crisis help / first insight / first joy |
| Quiet invite once per intention | Stacked meters + journey + entitlement theatre |
| Relief · confidence · time · consistency · understanding | Access fee to the room |

| Law | Rule |
|---|---|
| P1 | Entitlements / RevenueCat / pricing **unchanged** unless a separate Founder order says otherwise |
| P2 | Presentation must obey Pack 5 continuity study |
| P3 | Emotional · PTM seasonal core · Home NRT/Begin remain free forever |
| P4 | Health Lab / deep plans only after Care trust (policy) |
| P5 | `violatesAmyNestVoice` patterns fail manufacturing |

---

### 8. Loading — waiting · skeleton · progress

| Law | Rule |
|---|---|
| L1 | Waiting is calm companionship — never “Running adaptive AI orchestration…” theatre |
| L2 | Skeleton matches sanctuary materials — not rainbow progress fireworks |
| L3 | Progress only when it helps the parent act (feed timer, plan steps) — never XP bars |
| L4 | Prefer soft ambient continuity over spinner mall |

---

### 9. Empty states

| Law | Rule |
|---|---|
| X1 | Empty = gentle guidance to the next right act — never a blank SaaS table |
| X2 | Never upsell from empty |
| X3 | Offer one clear path back to room / Home |

---

### 10. Error states

| Law | Rule |
|---|---|
| R1 | Steady tone — Notice · Guide · Support — never blame |
| R2 | Retry without guilt |
| R3 | Preserve parent work where possible |
| R4 | No “unlock to fix” framing |

---

### 11. Success states

| Law | Rule |
|---|---|
| S1 | Quiet acknowledgment — never confetti / XP / artificial celebrate |
| S2 | Success ends in life: Home, continue care, or rest |
| S3 | Forbidden: streaks-as-pressure, bonus stars, leaderboard pops |

---

### 12. Completion — how the parent leaves

| Law | Rule |
|---|---|
| C1 | Completion ritual mirrors Parent Hub exit panel spirit: Home · continue · another room/path |
| C2 | Life continues — never restart the module as a mall |
| C3 | If value was felt, Premium invite may appear **once**, as continuity — never as unlock |
| C4 | Parent should feel held, not processed |

# 2. Mandatory Apple rules

Every destination must pass **all** of the following or it does not ship as manufactured.

| # | Apple rule | Fail if… |
|---|---|---|
| A1 | **Same home** | Feels like a separate application |
| A2 | **Same light** | Hard-cut to neon / purple galaxy / clinical white SaaS |
| A3 | **Same material system** | New glass planet / HubModule utility shell as product truth |
| A4 | **Same emotional voice** | Unlock · FOMO · urgency · guilt · score |
| A5 | **Same calm** | Dashboard density, marketplace browse, game hype |
| A6 | **Same photography language** | Emoji grid / illustration mall as opening hero without FE grammar |
| A7 | **No product marketing** | Try Free · Explore Free · PRO · Limited · Join thousands |
| A8 | **No SaaS energy** | Settings-first, metric-first, unlock-first |

**Apple one-breath test:**  
Hide logo and brand name. Would a parent who knows AmyNest still recognize this room as the same home Welcome introduced?

**Required answer: YES.**

# 3. Forbidden patterns (instant fail)

- Feature mall / eight equal groups as module home  
- XP · coins · Level · streak pressure · mastery rings as Hub/module chrome  
- Unlock theatre · peek-ahead · “Unlock All Learning”  
- Violet “Unlock with Premium” as primary voice  
- Try Free / Explore Free shelf badges as opening chrome  
- Neon game OS / achievement marketplace as default Moments face  
- Patent / science-tip marketing headers inside modules  
- Duplicate CTA stacks · artificial urgency  
- Gamification on Parent Hub or destination opening  
- Touching Welcome / Signup / Discovery / Today Home freezes to “fix” a module

# 7. Definition of Done

A module is **COMPLETE** only when:

1. All Production Manufacturing Checklist items pass  
2. All Apple Checklist items pass  
3. All Founder Checklist items pass  
4. Six Reviews all PASS  
5. Blind recognition test = YES  
6. Premium voice uses `PREMIUM_VOICE` only (no unlock theatre)  
7. Parent can enter from Hub and leave to life without emotional whiplash  
8. Implementation review doc filed under `docs/v2/` for that module  
9. Flag + rollback verified  
10. Founder explicitly accepts the manufactured module  

**Not Done:** “Looks better” · “Ships badges quieter” · “Hub slot only, standalone still another app” (unless Founder scopes Hub-only pass).

**Default manufacturing scope:** Hub entry **and** primary standalone route continuity — because immersion breaks at either cut.
