## Would Apple ship this experience?

**NO**

Remaining reasons:

1. **Chrome dialect mix** — sanctuary hero over dashboard timeline + bottom nav still feels like two products stacked, not one continuous surface.  
2. **Tab label “Dashboard”** — contradicts Home emotional naming (nav frozen this phase).  
3. **Timeline competition** — execution list remains visible; Apple would further quiet or fold it until after Begin.  
4. **Photography scale** — Home memory is compact; Welcome/Discovery give photography more authority.  
5. **Desktop** — bottom nav is mobile-first; desktop Home still inherits dense patterns when flag-off widgets appear in other breakpoints.

These are polish/architecture follow-ups — **not** Parent Hub work.
