### Framework owns (cannot close with CSS alone)

| Boundary | Why CSS fails |
|----------|----------------|
| **ChatPlatform keyboard / `adjustResize` / scroll contract** | Layout owned by engine; Nest cannot replace without rewriting ChatPlatform |
| **Mode tabs / WEB_MODES IA** | Product surface generated by Assistant; header hidden when nested, but mode product remains if exposed elsewhere |
| **`Loader2` + `animate-spin`** | Behavioral loading language inside black-box; Nest prepare pulse would require component swap |
| **`style={{ height: minHeightPx }}` on textarea** | Inline style wins over stylesheet |
| **Topic grid / interactive message tree** | DOM + logic generated by ChatPlatform |
| **Quota / paywall / briefing cards** | Product gates inside Assistant |
| **AmyIcon ring / prop sizes** | Prop-driven chrome |
