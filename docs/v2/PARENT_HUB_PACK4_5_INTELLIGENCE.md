## Mission

Parent Hub must stop behaving like a **navigation menu**.  
It must behave like a **parent companion**.

The parent should rarely need to decide where to start.  
AmyNest should gently recommend the **right room** — then Pack 4 already recommends the right path inside that room.

**This pack studies the intelligence layer only.**  
No routing changes until Founder approval.

## Companion principles (anti-creepy)

### Allowed signals (already shared or completed)

| Signal | Source | Why legitimate |
|---|---|---|
| Child age / age-months | Profile / Discovery | Parent told us |
| Infant cohort (0–24m) | Derived from age | Explicit life stage |
| Discovery today-world / focus (if stored) | Day-0 answers parent gave | Parent volunteered |
| Explicit Hub deep link / Path step target | Parent or product navigation | Intentional |
| Recent Hub room/path completions (short window) | Feature usage / client session parent already performed | Continuity, not stalking |
| Local time-of-day bucket | Device clock | Situational, not identity |
| Infant care logs **parent already entered** (sleep/feed gap) | Infant Hub data they created | Care continuity |
| Speech Coach sessions started/completed | Product the parent used | Skill continuity |
| PTM season window | Calendar utility already in Hub | Seasonal help |
| Active child selected | Parent choice | Context switch |

### Forbidden signals / language

| Forbidden | Why |
|---|---|
| Mic / camera / notification content inference | Surveillance |
| “We detected your stress” / emotion from biometrics | Creepy |
| Purchasing / location stalking | Out of scope · trust break |
| Inferring from private messages or contacts | Creepy |
| Silent scoring of “bad parent” | Guilt · anti-Steady |
| Opening Hub because of boredom / engagement optimization | Entry Law R7/R10 |
| Suggesting rooms from vanity metrics (points, streaks theatre) | Gamification forbidden |
| Inventing needs the parent never shared | Fiction ≠ companionship |

### Language law for any future copy

| Use | Never use |
|---|---|
| “Care may help with today’s sleep.” | “We noticed you’re failing at nights.” |
| “Help — when words are hard.” | “Your usage shows anxiety.” |
| “Ten quiet minutes?” | “You haven’t bonded enough.” |
| “Continue where you left off.” | “You’re behind on Hub goals.” |

If the reason cannot be said calmly to the parent’s face, the signal is forbidden.

## Recommendation engine (study design — not built)

### Output contract (future)

```ts
type HubRoomSuggestion = {
  room: "help" | "understand" | "care" | "moments" | null;
  /** 0–1; only auto-enter room when ≥ threshold */
  confidence: number;
  /** Calm, parent-facing reason key — must be sayable */
  reasonKey: string;
  /** Which allowed signals fired — for debug / audit, not UI guilt */
  signalsUsed: string[];
  /** Never true when Entry Law forbids Hub */
  mayOpenHub: boolean;
};
```

### Decision order (future)

```text
1. Entry Law gate
   → if action-enough / browse / mid-routine / post-discovery-first → room=null, mayOpenHub=false

2. Explicit intent
   → deep link / Path step with room → that room (confidence 1)

3. Hard life-stage
   → infant + Hub tab → Care (high)

4. Fresh completed signals (parent-authored)
   → sleep/feed gap logs → Care
   → speech session anxiety continuity → Help
   → guidance/meaning streak → Understand
   → presence completions → Moments

5. Short-term continuity (repeated room usage)
   → last 1–3 Hub sessions same room → keep that room
   → Moments streak → Moments + Presence path (Pack 4)

6. Soft situational (local clock + Discovery focus)
   → only if confidence still clear
   → else null → show four doors

7. Never invent a fifth intention
```

### Confidence policy

| Confidence | Behavior (future UI — not now) |
|---|---|
| ≥ 0.8 | May **enter** suggested room on Hub open |
| 0.5–0.8 | Doors overview with **one gently highlighted door** (not auto-enter) |
| < 0.5 | Four equal doors — companion stays quiet |
| `mayOpenHub=false` | Do not surface Hub suggestion from Home |

**Wrong room is worse than asking.**  
Silence is Steady. Guessing is SaaS.

### Relationship to Pack 4

| Layer | Owns |

Intelligence must never bypass Pack 4’s single path recommendation or Exit Law.
