## Mission

Design Premium so it feels like **continued support**, never like **content locking**.

| Law | Premium consequence |
|---|---|
| Parent Hub Constitution | Four rooms only; Steady tone; no FOMO · unlock · guilt |
| Today Home Law | Home NRT + Begin stay free forever |
| Home ↔ Hub Boundary | Never paywall an action that belongs on Today Home |
| Entry Law | Never open Hub as a shop |
| Value before payment | Invite only after trust is felt |
| AmyNest Philosophy | Relief, never interruption (`PREMIUM_VOICE`) |

**Premium must feel like:**

> “We can continue helping you.”

**Never:**

> “Pay to continue.”
