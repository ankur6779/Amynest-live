## Day One question

Should the parent feel **achievement** or **relief**?

**Relief.**

Nest Presence after a small parenting step is: *I showed up. I can rest.* Not: *I leveled up. What's next?*

Achievement is a scoreboard emotion — checkmarks, primary paint, “continue” funnels. Relief is an afterglow — quiet honor, one door home, nothing asking for more performance.

**Today's Success leans achievement** (trophy check · elevated panel · Coach as primary Bloom · Ask Amy as third ask), even while copy tries to speak relief (“Confidence grows… not from doing everything”). The words apologize for a UI that still hustles.

If Apple + Headspace had designed this on Day One, Success would be almost empty: one soft acknowledgment, one way back to Today. Coach would wait. Premium would be invisible.

## Special reviews

### Checkmark

| Current | Decision | WHY |
|---------|----------|-----|
| Lucide `Check` in orb, `text-primary` | **MERGE** | Acknowledgment mark OK; primary-colored “done!” = achievement UI. Soft mist / peer presence — not a badge. |
| Soft Plate orb + emit around check | **KEEP** · **WHISPER** | Nest presence vessel — keep quiet emit; don't let it outshine the H1. |
| Check as co-hero with H1 | **MERGE** | Relief hero is the *words*. Mark peers or whispers. |
| Check as trophy / gamification | **DELETE** | No streaks, confetti (already absent — **KEEP** that absence). Don't let the check replace them. |

**Relief test:** If the check were gone, would the parent still feel held by the copy? If yes, the check is optional whisper. If the screen needs the check to feel “done,” it is still a task app.

## What Mission Success would feel like if AmyNest had never been a SaaS product

The practice ends. The room does not congratulate you with a badge. It simply says: that was a real step. You finished the soft thing you came to do. You do not have to do everything.

There is one obvious, warm way back to Today — as if someone turned down the lights and opened the door home. If Amy Coach might help with the worry you already named, her name is mentioned once, quietly, like a note on the table — not a campaign. Nobody asks about Premium. Nobody opens Ask Amy. Nobody turns relief into a funnel.

You feel lighter. Not louder.
