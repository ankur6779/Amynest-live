# AmyNest V2 — Industrial Design Proposal

**Lens:** Jony Ive · Headspace Design · Apple Human Interface  
**Mode:** High-fidelity proposal only — **no implementation**  
**Constraint:** Presentation only. Flows, logic, Brain, routing, Experience — untouched.

---

## Design oath

We are not redesigning an app.  
We are designing an object that happens to live on a phone.

If a control does not serve the parent’s calm, it is decoration.  
Decoration is removed.

> Every screen:  
> **one emotional hero** · **one obvious action** · **one supporting object**  
> Nothing else competes.

**Targets**

| Metric | Direction |
|--------|-----------|
| Visible UI | **−30%** (fewer chrome, labels, borders, competing CTAs) |
| Perceived premium | **×2** (materials, air, light, restraint) |

---

## How the three voices decide

### Jony Ive
- Essentialism: if it can be removed, remove it.
- Materials over metaphors: soft plate, atmosphere, light — not “cards.”
- The object has a single silhouette. Today is not a stack of products.

### Headspace Design
- Atmosphere is the product.
- Ritual over information architecture.
- The parent’s nervous system is the user. Loud UI is a failure.

### Apple HIG (spirit)
- Clarity: one primary action is unmistakable.
- Deference: UI gets out of the way of content (here: Amy’s care).
- Depth: light and layering, not drop-shadow theater.
- Consistency: same three materials everywhere; never a new pattern per screen.

---

## The law of three (binding)

| Slot | What it is | What it is not |
|------|------------|----------------|
| **Emotional hero** | The feeling the parent should have in the first second — light, word, or presence | A section label, a logo bar, a chip row |
| **Obvious action** | The one thing to do next — single bloom control | Two equal buttons, tab noise, “also try…” |
| **Supporting object** | One quiet thing that earns trust — memory line, soft plate, orb | A second CTA, a third card, a badge cluster |

**Everything else** either moves below the fold into a quieter chapter, or is deleted from the visual field.

---

## −30% visible UI — what leaves

| Remove / hide | Why |
|---------------|-----|
| Top logo strip on V2 shells | Chrome competes with hero |
| Section eyebrow labels (“RIGHT NOW”, “AMY COACH · LONG-TERM”) as visual equals | Hierarchy becomes a filing cabinet |
| Equal-weight bordered cards for every chapter | Dashboard silhouette |
| Underline / pill tab indicators | Noise; active = weight + soft fill only |
| Dual CTAs of equal strength | Breaks “one obvious action” |
| Chip rows, patent badges, rainbow marks in-shell | Marketing residue |
| Hard card borders | Industrial products don’t outline every surface |
| Lucide icon decoration next to every title | Icons only when they *are* the supporting object |

**What stays (quieter):** Back only when needed; tab bar as frosted instrument, not a billboard; “Not right now” as breath text, never a second hero button.

---

## ×2 perceived premium — what arrives

| Add / intensify | Craft |
|-----------------|-------|
| Atmosphere field | Soft radial night light; time-of-day hush |
| One display line | Large, calm type; almost nothing beside it |
| Soft plate | Large radius, no border, inner highlight like milled aluminum-glass |
| Bloom action | Single accent material; generous hit target; rests in air |
| Silence | 40–56px between chapters; empty is a feature |
| Amy as light | Orb / glow presence — not a bouncing mascot in the header |
| Sheet glass | Guest / Premium gates: luminous edge, not modal chrome |

Premium is not more detail.  
Premium is **fewer decisions for the eye**.

## Screen compositions (1 + 1 + 1)

Flows unchanged. Only what the eye is allowed to see.

### Front Door
| Slot | Content |
|------|---------|
| Hero | Amy orb — presence, not UI |
| Action | Continue / choose (single bloom when a choice is ready) |
| Support | One whispered line of care |

Age / worry choices: **supporting objects as soft plates**, never a form. Progress: hairline light — almost invisible.

### Today
| Slot | Content |
|------|---------|
| Hero | One word of focus as display type (“Sleep”) — the emotional climate |
| Action | Mission bloom (“Start” / continue today’s step) |
| Support | Soft plate: today’s step for {child} — title + 3 min only |

**Below fold (quiet, no competition):** Coach whisper · Ask Amy whisper · Premium whisper — each a single line + chevron, **not** full cards. −30% comes mostly from here.

### Mission
| Slot | Content |
|------|---------|
| Hero | The step’s emotional stage (atmosphere for sleep / speech) |
| Action | Mark complete / primary ritual control |
| Support | One short how-to object (soft sequence, max 3 lines visible) |

Success screen: hero = warm light; action = Back to today; support = one sentence of confidence. No second celebration CTA competing.

### Coach
| Slot | Content |
|------|---------|

| Action | Continue |
| Support | Soft plate — plan essence in one breath |

“Not right now” = text in air, not a second button block.

### Ask Amy

## Material study (industrial)

| Material | Physical metaphor | Digital expression |
|----------|-------------------|--------------------|
| Atmosphere | Room at dusk | Full-bleed field + soft radial light |
| Soft plate | Ceramic / frosted glass | Large radius, 6–8% white, no stroke |
| Bloom | Polished warm metal | Single accent fill for the one action |
| Sheet glass | Laminated glass pane | Blur + 1px luminous edge |
| Hairline | Engraved mark | Progress, dividers almost invisible |

Never: neon glow rings, multi-shadow stacks, rainbow gradients in-product.

---

## Typography as material

- **Hero type:** large, calm, almost luxurious — one line  
- **Action type:** medium, clear, on bloom  
- **Support type:** smaller, generous leading, mist color  

If a label must exist, it is quieter than the hero by a full step — not bold-gray shouting “SECTION.”
