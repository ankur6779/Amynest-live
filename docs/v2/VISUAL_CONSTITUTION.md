# AmyNest Visual Constitution

**Status:** Permanent emotional DNA — **binding for every future surface**  
**Mode:** Soul definition only — **no screen redesign · no implementation**  
**Identity stack:** Nest Presence  
*(Soul: Presence · Climate: Atmosphere · Discipline: Essential Object · Service: Hospitality)*  
**Production system lock:** [`DESIGN_CONSTITUTION.md`](./DESIGN_CONSTITUTION.md) — typography, buttons, surfaces, nav, lighting presets, motion, components

---

## Preamble

AmyNest is not a dashboard.  
AmyNest is not a chatbot skin.  
AmyNest is not EdTech purple.

AmyNest is a **place that holds a parent**.

Every future screen — Today, Coach, Ask Amy, Premium, Landing, Signup, native shells, marketing, email, store — inherits this DNA.  
Local invention that contradicts this Constitution is a defect.

Craft scales, radii, and component anatomy are frozen in the **Design Constitution**. This file holds the soul.

> **Law of three (universal)**  
> One emotional hero · one obvious action · one supporting object.  
> Nothing else competes.

---

## 1. Emotional climate

### Core climate: Nest Presence

| Quality | Definition |
|---------|------------|
| **Held** | The parent feels accompanied, never processed |
| **Quiet** | Volume of UI is low; confidence is high |
| **Warm** | Never clinical cold; never carnival bright |
| **Inevitable** | The next step feels obvious, not marketed |
| **Human** | Materials feel touched by care, not by growth teams |

### Lighting presets (locked — three only)

Production lighting is frozen in the Design Constitution:

| Preset | Emotional job |
|--------|---------------|
| **Morning** | Clear start · soft courage |
| **Evening** | Held transition · wind-down |
| **Night** | Regulate · protect sleep |

### Tempo & density overlays (not new lights)

Same preset; different breath — never a fourth lighting world:

| Overlay | Shift |
|---------|-------|
| **Unhurried** | Wider air; slower motion; fewer instruments |
| **Celebration** | Brief warm bloom (≤1s); one soft mark of completion; **no confetti, streaks, or points theater** |
| **Quiet** | Near-invisible chrome; hero may be presence alone; action can wait |

Presets change **light**. Overlays change **tempo and density**. Materials language never changes.

## 2. Atmosphere

Atmosphere is the first product.

| Rule | Constitution |
|------|----------------|
| Field | Every surface sits in a **Nest field** — a continuous environmental plane, not a flat app gray/navy fill |
| Depth | Soft radial “room light,” not layered panels fighting for attention |
| Emptiness | Empty space is **Ma** — intentional. Filling empty space is a regression |
| Time | Atmosphere may shift by climate mode; the brand must still read as AmyNest in one glance |
| Forbidden | Loud mesh gradients, rainbow auroras, neon fog, dashboard wallpaper patterns |

**Ambient gradients** (allowed family only):

- Nest night → soft plum-ink depth  
- Mist lift → pale warm grey into quiet blue-hour  
- Dawn breath → faint apricot at the horizon of the field (morning)  
- Lunar rim → cool edge light (night)  

Gradients are **weather**, not decoration. Max one ambient system per screen.

---

## 3. Lighting

Light behaves like a room, not like a UI kit.

| Principle | Rule |
|-----------|------|
| Key light | Soft, single source feel — above / slightly aside |
| Glow | Reserved for Amy presence and rare celebration bloom |
| Shadows | Soft, short, honest — never multi-layer drop-shadow stacks |
| Specular | One quiet highlight on bloom actions or glass sheets |
| Night | Lower overall luminance; protect melatonin-friendly calm |
| Forbidden | Hard spotlights on every card, glow spam, iridescent chrome |

---

## 4. Typography

Type is material.

| Role | Character |
|------|-----------|
| **Display** | One emotional line. Large. Calm. Almost luxurious. Used sparingly |
| **Body** | Humanist, generous leading, readable in fatigue |
| **Meta** | Whisper only — never equal to the hero |
| **Action** | Clear, medium, on bloom — never decorative script on CTAs |

**Laws**

- One loud line per view.  
- Labels are quieter than content by a full step.  
- No badge typography clusters.  
- Numerals for time (“3 min”) are soft instruments, not scoreboards.

---

## 5. Materials

AmyNest is built from **four materials**. No fifth without Founder amendment.

| Material | Physical metaphor | Use |
|----------|-------------------|-----|
| **Atmosphere** | Room at dusk / dawn | Background field; text may float here |
| **Soft plate** | Ceramic / frosted glass | The single supporting object when needed |
| **Bloom** | Warm polished accent | The one obvious action |
| **Sheet glass** | Laminated glass | Temporary gates (account, premium continuity) |

**Forbidden materials:** neon plastic, heavy bordered “cards” as default, rainbow glass, skeuomorphic toys, stock glassmorphism soup.

---

## 6. Motion

Motion is breath, not entertainment.

| Class | Behavior |
|-------|----------|
| Enter | Soft settle (opacity + slight rise) — never bounce |
| Press | Immediate, small, tactile — industrial click, not jelly |
| Page | Slow enough to feel intentional; fast enough to feel confident |
| Celebration | One warm light bloom; ≤1s emotional peak; then quiet |
| Ambient | Optional ultra-slow atmosphere drift; **off under reduced motion** |

**Laws**

- Prefer fewer moving things over choreography.  
- Reduced motion: lighting and layout remain; motion stops.  
- No streak flames, particle confetti, or mascot dance loops in product.

---

## 7. Spacing

Space is structure.

| Token spirit | Intent |
|--------------|--------|
| Edge air | Generous — the product is not desperate for pixels |
| Hero → action | Clear pause — the eye arrives, then acts |
| Between chapters | Wide — chapters are not a feed |
| Inside plate | Comfortable — content is not cramped |

**Law:** If densifying helps “fit more features,” refuse. Density is a product smell.

---

## 8. Illustration

Illustration is presence, not sticker pack.

| Allowed | Forbidden |
|---------|-----------|
| Abstract nest cavity, soft horizons, light orbs | Mascot sticker sheets |
| Single symbolic object per view | Icon rows explaining features |
| Quiet line / wash consistent with materials | Loud flat vector “EdTech” scenes |
| Empty-as-beauty (possibility) | Hollow SaaS tiles pretending to be content |

Illustration never competes with the emotional hero — it *is* the hero or the supporting object, never both plus more.

---

## 9. Photography

Photography is rare and human.

| Rule | Constitution |
|------|----------------|
| Subject | Real parenting atmosphere — hands, quiet rooms, night lamps — not stock “happy dashboard family” |
| Color | Graded into Nest climate; never neon |
| Role | Hero or support — never a collage |
| Faces | Prefer care and calm over performance smiles |
| Product UI shots | Show Law of three; never feature grids |

Marketing may use richer photography; **in-product** photography is sparse and deferential.

---

## 10. Orb behavior (Amy presence)

Amy’s orb is the sacred presence mark.

| State | Behavior |
|-------|----------|
| **Idle** | Soft stable glow; almost still |
| **Listening / with you** | Gentle breathe (scale/luminance); never frantic |
| **Guiding** | Steady bloom toward the obvious action — light leads, UI follows |
| **Celebrate** | Single warm pulse, then rest |
| **Reduced motion** | Static glow; no breathe |

**Laws**

- Orb is not a header logo toy.  
- Orb does not bounce for delight.  
- Orb does not appear on every chrome surface — presence is earned.  
- When the orb is the emotional hero, nothing else glows.

## 11. Ambient gradients

Gradients are climate instruments.

| Name | Use |
|------|-----|
| Nest Night | Default in-product depth |
| Mist Lift | Morning / clarity |
| Dawn Breath | Hopeful starts; soft celebration afterglow |
| Lunar Rim | Night care edges |

**Laws**

- One ambient system per surface.  
- No animated rainbow sweeps.  
- Gradients never carry brand “tech energy”; they carry **weather**.

## 12. Color ethics (language, not palette file)

This Constitution defines **roles**, not a token dump:

| Role | Spirit |
|------|--------|
| Ink | Warm near-black — readable, human |
| Mist | Soft secondary — whispers |
| Nest night | Deep atmosphere — held |
| Bloom | Single action accent — warm, never alarm red, never carnival orange |
| Glow | Light of presence — restrained |

**Forbidden:** competing accents; purple-pink-cyan identity soup; success-green gamification; urgency red for normal parenting steps.

---

## 13. Interaction ethics

| Do | Don’t |
|----|-------|
| One bloom action | Peer CTAs of equal weight |
| Soft dismiss as breath text | Secondary button competing with hero action |
| Sheet glass for trust gates | Hard Sign-in walls as visual language |
| Tactile press | Hover theater on mobile |

---

## 14. Inheritance rule

Before any future screen ships, ask:

1. What is the **emotional hero**?  
2. What is the **one obvious action**?  
3. What is the **one supporting object**?  
4. Which **climate mode** is this?  
5. Which **materials** are in use — and is a fifth sneaking in?  
6. Does anything compete?

If any answer is unclear, the screen is not AmyNest yet.
