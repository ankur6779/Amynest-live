## Law

1. No room may begin implementation until the **previous** room in Founder Execution Order is **APPROVED**.  
2. Only **APPROVED** rooms unlock the next room.  
3. Never work on two rooms simultaneously.  
4. One room. One emotional question. One Founder approval. Then move forward.  
5. Keep (order 1) has no predecessor — it is the only room unlocked at start.

## Status values

| Status | Meaning |
|--------|---------|
| **NOT_STARTED** | Locked or unlocked but no implementation work begun |
| **IN_PROGRESS** | Sole active room — implementation allowed |
| **FOUNDER_REVIEW** | Implementation paused — awaiting certification |
| **APPROVED** | Founder Room Certification passed — next room unlocks |
| **FROZEN** | APPROVED and closed — no further work except Founder reopen |

**REJECTED** is a certification outcome, not a standing status. On REJECTED → return room to **IN_PROGRESS**.
