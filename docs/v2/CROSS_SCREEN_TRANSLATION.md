# Cross-Screen Translation — One Nest or Nine Products?

**Mode:** Translation synthesis only. No code. No mockups. No redesign.  
**Inputs:** Landing · Signup · Today · Mission · Mission Success · Coach · Ask Amy · Premium · For Child translations  
**Frozen:** Constitution · Product · Features · Brain · Architecture · Routes  
**Question:** Do they belong to **one product** — or **nine different products**?

---

## Verdict

**Nine different products wearing fragments of one Constitution.**

Craft tokens (space ladder, Soft Plate, Bloom, lighting presets, Law of Three markers) are a shared spine. Lived screens still speak different dialects:

| Screen | Feels like |
|--------|------------|
| Landing | Marketing site / AI startup door (Nest path improving; brochure DNA remains until deletes land) |
| Signup | Neon auth portal |
| Today | Parenting dashboard |
| Mission | Checklist task app |
| Mission Success | Achievement + funnel fork |
| Coach | Setup wizard → signup gate |
| Ask Amy | ChatGPT starter + freemium gate |
| Premium | Subscription catalog |
| For Child | Empty “coming soon” tab |

A tired parent walking the guest path does not feel one Nest Presence. They feel costume changes.

**After the deletes in each translation land as one composition language:** they can become one product. Today they are not.
