# AmyNest V2 — Emotional Journey

**Status:** Emotion review only — **ignore UI · no implementation · no visual fixes**  
**Law:** Every screen moves emotion **one step**. Never jump.  
**Lens:** How the parent feels **before opening** → how they should feel **after leaving**.

---

## The allowed staircase

Emotion advances one tread at a time:

```
overwhelm / panic
    ↓
heard
    ↓
calm
    ↓
oriented
    ↓
hope
    ↓
ready
    ↓
doing
    ↓
honored
    ↓
confidence
    ↓
continuity (held over time)
```

Side paths (still one step):

```
uncertainty → reassured
alone → accompanied
ashamed → accepted
sold-to → invited   ← if a screen lands on “sold-to,” it has failed
trapped → free to leave
```

**Jump** = skipping a tread, reversing harshly, or stacking two destinations in one screen.

| | |
|--|--|

| **After** | Heard. A pause was allowed. Not fixed — met. |
| **Step** | Overwhelm → heard |
| **Flag** | None if the meter/brand don’t shove them into “onboarding mode” emotionally. If the screen feels like step 1 of 5, that is a jump: overwhelm → *processed*. |

## Emotional continuity rules

1. **One step per screen.** If copy wants two feelings, cut one.  
2. **Never reverse without care.** Overwhelm after calm is a product failure.  
3. **Gates may only invite.** Trapped is never a valid “after.”  
4. **Honor before enroll.** Success screens do not sell in the same breath.  
5. **Tabs are rooms, not funnels.** Lateral move ≠ emotional leap.  
6. **Empty is not hope.** Hollow structure drops the staircase.  
7. **Confidence is earned after doing + honor** — not from greeting copy alone.

## Ideal arc (full first session)

```
overwhelm
  → heard          (Breath)
  → oriented       (Age)
  → accompanied    (Name)
  → heard          (Worry — deepen, don’t jump)
  → calm           (Today arrive)
  → hope           (Mission visible)
  → doing          (Play)
  → honored        (Success)
  → confidence     (Return)
  → continuity     (only if invited — Premium later, soft)
```

Any session that ends at **sold-to**, **trapped**, **startled**, or **disappointed** has left the staircase.
