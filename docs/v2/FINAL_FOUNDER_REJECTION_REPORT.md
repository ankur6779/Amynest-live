## Apple — Would they ship this?

### **NO**

### Exactly why

1. **Not one product.** Guest path changes costume: Nest field → purple neon Signup → dashboard Today → checkbox Mission → Coach purple island → ChatGPT Ask Amy → plan-table Premium → empty For Child. Design Review fails at brand continuity.

2. **Landing is still a brochure** (even after Nest translation intent). First-party marketing residue, dual worlds, and “keep all sections” logic would not survive. Apple ships a threshold, not a catalog with dimmed modules.

3. **Signup is a neon portal.** Rotating rings, Meet AMY glass, purple void — forbidden against any Nest claim. Opacity-0.45 is not craft.

4. **Today is a dashboard.** Mission + Coach + Ask Amy + Premium as stacked chapters. Law of Three via opacity is rejected as unfinished hierarchy.

5. **Mission climax is “Mark complete.”** That is a task app. Apple does not ship self-report checkboxes as the emotional center of a parenting ritual.

6. **Success steals relief.** Honor copy is good; Coach-as-primary Bloom + Ask Amy stack is a funnel. Achievement UI (primary check) over relief.

7. **Coach is a setup wizard** ending in Continue → Signup. Fake timed prepare. Legacy purple Understanding mid-Nest path. Trap.

8. **Ask Amy is ChatGPT.** Prompt wall → assistant black box; account sheet before help. Freemium AI feature page.

9. **Premium is a rate card.** Care headline over plan rows, prices, badges, dual CTAs. Continuity letter it is not.

10. **For Child is an empty primary tab.** Named for the child, hope only, no living object. Apple removes empty tab bar items.

11. **Typography not lived.** Constitution type almost unused; invented scales per screen.

12. **Nav manufacturing defect.** Legacy `.app-footer` 72px dark shelf under whisper nav — CSS fighting the system.

13. **Compromise culture.** Tokens ahead of pixels; “recede” instead of delete; dual Nest/legacy paths. Apple rejects half-measures as the product.

**Apple one-liner:** Beautiful rules. Unshippable walk.

## Headspace — Would they ship this?

### **NO**

### Exactly why

1. **Sanctuary broken by anxiety surfaces.** Neon Signup, prompt walls, problem grids (Landing residue), plan shopping, account gates at need — the nervous system never settles for a full journey.

2. **Care → hustle pattern repeats.** Mission Success honor → Coach pitch. Ask Amy need → account sheet. Coach “ready” → Signup. Headspace never turns afterglow into onboarding.

3. **Checkbox Mission.** Practice is not hosted; completion is audited. That is productivity guilt, not presence.

4. **Fake prepare (Coach timers).** Performative “Amy is working” destroys trust — the opposite of meditation honesty.

5. **Today’s many asks.** Sleep-deprived parents get a stack of modules. Headspace home is one session invitation, not a control panel.

6. **ChatGPT Ask Amy.** Suggestion chips and chatbot silhouette are tool anxiety, not guided calm.

7. **Empty For Child.** Hope copy without a held practice is loneliness labeled as product.

8. **Language split.** “Amy remembers” fights “Generate My First Win,” “Mark complete,” “AI-powered.” One voice required for sanctuary.

9. **Premium shopping energy.** Even soft verbs cannot hide a SKU list as the emotional center after a care headline.

10. **Motion storm / identity flicker.** Purple rings and orb neon vs Nest stillness — cannot be the same wellness brand.

**Headspace one-liner:** Moments of calm copy inside a funnel that keeps waking the parent up.

---

## Airbnb — Would they ship this?

### **NO**

### Exactly why

1. **No belonging through place.** Entry is tools, wizards, catalogs — not a hosted home. Mascot and Soft Plates are not hospitality.

2. **Guest is treated as a lead, not a guest.** Account walls before help; Signup as Coach climax; save-progress on empty For Child — hospitality would host first.

3. **Brand of place flips.** Nest room → nightclub auth → dashboard → AI chat widget. A stay cannot change hotels every hallway.

4. **Today is an app home, not a morning with a host.** Module cards are property listings of features.

5. **Success is upsell at checkout.** Coach primary after “real step” is the amenity pitch before you’ve put your bags down.

6. **Premium is a rate card.** “Keep going with Amy” over prices is exactly the fake-hospitality pricing page Airbnb’s own craft would reject.

7. **For Child names the child on an empty room.** Putting a guest’s child’s name on a vacant suite is worse than no suite.

8. **Ask Amy is a concierge kiosk that demands ID before answering.** Wrong order for trust.

9. **Landing (if still brochure-length) is a marketplace of screens** — not a single invitation into a place.

10. **No photographic / lived human truth** as the emotional anchor across the walk — product chrome substitutes for belonging.

**Airbnb one-liner:** The copy says “stay with Amy.” The product checks you in through five different lobbies.

---

## Linear — Would they ship this?

### **NO**

### Exactly why

1. **Craft incomplete.** Constitution frozen on paper; pixels invent type, materials, and hierarchy. Linear ships the system or ships nothing.

2. **Opacity hierarchy is a known anti-pattern.** Receding Coach/Ask Amy/Premium/prompts/plans without deleting them is unfinished work dressed as Law of Three.

3. **Content freeze defeated design.** “Keep all Landing sections,” hollow-then-empty For Child, prompt wall kept as peer catalogue — craft requires editing.

4. **Dual codepaths / dual identities.** Nest vs purple legacy islands = unmaintainable product language and visible seams.

5. **Button democracy.** Outline, ghost, secondary, Bloom peers across Today, Success, Premium, For Child (outline-as-primary). One primary action rule broken repeatedly.

6. **Soft Plate wallpaper.** Same material for mission, coach, prompts, plans, prepare steps — no rarity, no hierarchy, visual fatigue.

7. **Dishonest progress.** Coach 0.9/1.8/2.8s step theatre fails craft integrity.

8. **Information architecture is a marketing novel** on Landing and a module feed on Today — not ruthless clarity.

9. **Empty nav destination.** Shipping For Child with no object fails the most basic IA craft test.

10. **Footer CSS vs whisper nav.** Manufacturing defect — the system fights itself. Linear would block merge.

11. **Optimistic sprint scores vs lived 66.** Measuring tokens as ship-ready is a process failure Linear would call out.

**Linear one-liner:** Strong design system docs. Weak deletion. Unshippable density and seams.

## What would have to be true to reopen ship (not a redesign brief — rejection exit criteria)

Only listed so the rejection is falsifiable. Not instructions to build now.

1. One Nest atmosphere and type from Landing through Signup — no purple islands.  
2. Today = companion (one hero, one Mission Bloom, one Amy line) — no module stack.  
3. Mission = ritual; Success = relief with one door home — no funnel stack.  
4. Coach = being seen — not wizard + fake prepare + signup climax.  
5. Ask Amy = help first — no prompt wall, no pre-help account sheet.  
6. Premium = continuity letter — price whisper, not catalog hero.  
7. For Child = one living step or absent from the bar.  
8. Nav whisper actually manufactured (no 72px dark shelf fight).  
9. Cross-screen reads as one product in a five-minute parent walk.

Until then: **unanimous NO.**
