# R1 — Opening Experience

### Business Goal
Convert install into a calm first open that parents want to continue.

### Emotional Goal
Quiet relief.  
“I can breathe here.”  
“I am in the right place.”

### Conversion Goal
First-open continuation.  
No account ask. No paywall. No feature tour.

### Engineering Scope
- First-open moment entry path only
- Block all competing destinations on first open
- No signup gate
- No premium gate
- No module mall
- Preserve one living presence focus
- Fast, reliable cold start into Opening moment

### Visual Scope
- Deep ink stage
- One warm living Amy light at center
- Sacred negative space
- No lifestyle collage
- No feature imagery
- Typography almost absent in first beat

### Animation Scope
- Breath-speed light inhale
- Presence settle + hold
- No bounce
- No particle carnival
- Optional soft arrival tone only if it deepens calm

### Success Criteria
- [ ] Parent feels calm in first 3 seconds with sound off
- [ ] Eye rests on one center; no competing subjects
- [ ] Zero asks before value
- [ ] Continuation rate from Opening → next moment rises
- [ ] Qualitative: “This feels premium and quiet”

### Risk
Opening looks like a splash ad, kids app intro, or feature trailer.  
If it sells, it fails.

---

# R2 — Trust Experience

### Business Goal
Make the parent believe AmyNest is about **this child**, not parents in general.

### Emotional Goal
Recognition.  
“She already sees my child.”

### Conversion Goal
Permission to receive a real recommendation.  
Trust before decision.

### Engineering Scope
- Capture / resolve minimum child identity needed for recognition
- Prefer feeling of understanding over long interrogation
- Feed Understand-stage inputs only (child, age, relevant today context)
- Do not open hubs, catalogs, or settings journeys here
- Reflect child-specific recognition back before any module entry

### Visual Scope
- Child as gravitational center
- Warm recognition aura
- Soft orbiting context signals (never badge strips)
- Portraiture language, not form language
- Wide calm negative space outside the child orbit

### Animation Scope
- Signals drift inward and magnetically settle
- Portrait resolves into focus
- No checklist tick rain
- No loading theater that feels like bureaucracy

### Success Criteria
- [ ] Parent can name whose journey this is within 3 seconds
- [ ] Experience feels personal without feeling like paperwork
- [ ] Drop-off during understanding falls
- [ ] Qualitative: “This is about my child”
- [ ] Ready handoff into one decision moment

### Risk
Trust becomes onboarding forms.  
If it feels like setup labor, trust dies.

---

# R3 — Today's Next Right Thing

### Business Goal
Deliver the core product promise for the first time.

### Emotional Goal
Clarity.  
“I know what to do.”

### Conversion Goal
First proof of usefulness.  
Experience value before signup pressure.

### Engineering Scope
- Produce exactly one next right thing for this child today
- Suppress multi-option malls and destination pickers
- Decision must be specific, doable, kind
- Wire Decide-stage responsibility only
- Handoff cleanly into Mission execution
- No premium requirement to see the first next right thing

### Visual Scope
- Apple-grade single reveal
- Spotlight on one luminous decision
- Background world recedes
- Radical emptiness around the one truth
- One primary line; optional whisper support only

### Animation Scope
- Fog-lift reveal
- Ceremonial slow push-in
- Object materializes with gravity
- No carousel
- No multi-card fanout
- No pop / bounce

### Success Criteria
- [ ] Parent can state today’s next right thing in one sentence
- [ ] No competing CTAs visible in the reveal beat
- [ ] First-value completion intent rises
- [ ] Qualitative: “This is obvious and doable”
- [ ] Product becomes understandable without explanation

### Risk
Reveal becomes a dashboard.  
Many options = uncertainty = product failure.

---

# R4 — Mission Experience

### Business Goal
Turn the recommendation into lived completion.

### Emotional Goal
Competence and warm pride.  
“I did the right thing for my child.”

### Conversion Goal
First completion.  
Emotional attachment through usefulness.  
Seed daily habit.

### Engineering Scope
- Execute the one next right thing only
- Support Complete / Skip / Delay as reality outcomes
- Keep parent inside execution of today’s mission
- Return to today’s truth after action
- Modules may serve execution only when selected as today’s thing
- No side-quest destinations during first mission

### Visual Scope
- Companion presence beside the parent
- Single human progress arc
- Dignity in completion
- No trophy carnival
- Progress has air; no side clutter

### Animation Scope
- Pressure → commit → release → settle
- Sunrise-one-degree success
- Soft seal / exhale
- Never coin shower
- Never badge explosion

### Success Criteria
- [ ] Parent can complete the mission without confusion
- [ ] Completion feels dignified, not childish
- [ ] First-session completion rate rises
- [ ] Return intent for tomorrow rises
- [ ] Qualitative: “That counted”

### Risk
Mission becomes a mini-game or content browser.  
If completion feels fake, habit never forms.

# R5 — Memory Experience

### Business Goal
Prove AmyNest is a living companion, not a one-session tool.

### Emotional Goal
Being accompanied.  
“I am not starting over.”

### Conversion Goal
Desire for permanence.  
Create fear of losing continuity.

### Engineering Scope
- Remember reality: completion, skip, delay, patterns, confidence
- Reflect continuity without archive overload
- No shame language for skips/delays
- Feed Improve-stage so tomorrow can be smarter
- Show continuity after first completion before signup ask

### Visual Scope
- Child returns with afterglow
- Memory as aura / ribbon, not timeline clutter
- Familiar motif continuity from prior boards
- One soft continuity line max
- No stats-as-hero

### Animation Scope
- Ribbon reconnects once
- Past light breathes into present
- Stillness after continuity lands
- No report-building montage

### Success Criteria
- [ ] Parent feels remembered within 3 seconds of return/recall
- [ ] No timeline clutter required to understand continuity
- [ ] Desire-to-keep signal rises
- [ ] Qualitative: “She remembers us”
- [ ] Clean emotional runway into Signup

### Risk
Memory becomes analytics.  
Surveillance energy destroys trust.

# R6 — Signup Experience

### Business Goal
Convert desire into account creation.

### Emotional Goal
Ownership.  
“I want to keep this.”

### Conversion Goal
Signup as preservation.  
Not compliance. Not gatekeeping mid-success.

### Engineering Scope
- Trigger signup only after value + memory are felt
- Preserve journey continuity through account creation
- No hostage pattern that deletes progress if declined
- Keep identity capture minimal
- Maintain Keep-language over Account-language in experience order
- Do not introduce premium hard-sell inside signup beat

### Visual Scope
- Keepsake / sanctuary board
- Gathered journey held in protective light
- Zero bureaucracy-as-hero
- Warm gold-ivory protection over deep calm field
- Practical identity UI remains visually secondary to preservation feeling

### Animation Scope
- Inward gather of what mattered
- Safe hold / seal
- No snatch
- No countdown
- No punishment exit

### Success Criteria
- [ ] Signup ask appears after love, never before first value
- [ ] Parents describe signup as “keeping,” not “registering”
- [ ] Signup conversion rises without increasing hostility
- [ ] Declining signup does not erase first-value memory in-session
- [ ] Qualitative: “I want to save this”

### Risk
Signup feels like a wall.  
If it appears too early, trust collapses and install→signup dies.

# R7 — Subscription Experience

### Business Goal
Convert daily habit into paid continuity.

### Emotional Goal
Obviousness.  
“Of course I continue.”

### Conversion Goal
Subscription as uninterrupted care.  
Not feature shopping. Not urgency theater.

### Engineering Scope
- Offer subscription only after repeated usefulness / habit signal
- Frame access as continuity of the loop, not module unlock catalog
- No fake scarcity countdowns as primary pattern
- Keep free-path dignity intact where promised
- Ensure paid state protects daily next-right-thing continuity
- Do not redefine product as premium feature mall

### Visual Scope
- Continuum-of-care horizon
- Kept light extending across mornings
- Features invisible as merchandise
- Stable enduring light; no discount sticker energy
- Fairness language second; continuity promise first

### Animation Scope
- Slow forward glide into future mornings
- Chapter-turn motion
- No panic urgency motion
- No flash-sale pulse

### Success Criteria
- [ ] Parents understand what they continue: daily next right thing
- [ ] Subscription feels obvious to habitual users
- [ ] Trial/paid conversion rises without trust complaints
- [ ] Support tickets about “forced paywall” fall
- [ ] Qualitative: “I’m paying to keep the care, not buy add-ons”

### Risk
Subscription looks like buying Premium features.  
If it becomes a store, AmyNest becomes ordinary.

## Cross-Release Production Checklist

### Sequence control
- [ ] R1 ships before R2 polish expands
- [ ] R3 cannot be skipped; it is the product proof
- [ ] R6 cannot precede R3–R5 value
- [ ] R7 cannot precede habit evidence

### Continuity control
- [ ] Same living-light motif across R1–R7
- [ ] Breath-speed motion language preserved
- [ ] One-subject rule enforced in every release
- [ ] Dignity-over-dopamine rule enforced in R4/R5/R7

### Business control
- [ ] Each release maps to Install→Subscription stages
- [ ] Each release has one primary conversion goal
- [ ] No release invents a new product promise

### Acceptance gate for every release
1. Felt in 3 seconds without explanation  
2. One subject only  
3. Advances Trust or Conversion without force  
4. Serves next right thing for this child today  
5. Does not reopen feature-mall behavior  

If a release fails the gate, it does not ship.
