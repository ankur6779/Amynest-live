## The Law

There is only

one Amy.

Coach remembers.

Mission remembers.

Ask Amy remembers.

Child remembers.

Premium remembers.

No room

owns memory.

The Home owns memory.

Engines only read

what the Home already knows.

---

## Meaning

| Truth | Implication |
|-------|-------------|
| **One Amy** | One mind, one continuity of care — not Coach-Amy, Ask-Amy, Mission-Amy as separate beings |
| **Rooms remember (feeling)** | In every room, Amy feels continuous — she already knows |
| **Home owns memory** | Persistence, identity, child context, preferences, journey — Home substrate |
| **Engines only read** | Coach, Mission, Ask Amy, Child, Premium engines **consume** Home memory; they do not own silos |

---

## Ownership

| Owner | Owns | Does not own |
|-------|------|--------------|
| **Home** | Memory — what Amy knows across rooms | Room emotion; engine execution |
| **Rooms** | Emotion of being remembered | Private memory stores that other rooms cannot know |
| **Engines** | Execution that **reads** Home memory | Authoritative memory of their own |

---

## Forbidden

- Per-engine memory that Amy “forgets” when the parent changes room  
- Room-local identity that contradicts Home memory  
- Engines writing a second Amy (separate profiles, separate histories as truth)  
- Features that require the parent to re-introduce the child to Amy  

---

## Allowed

- Engines caching **reads** of Home memory for latency (ephemeral; Home remains source of truth)  
- Room presentation of what Home already knows  
- Write paths that **update Home memory** (not engine-private truth)

---

## Founder gate

> Is there still only one Amy — and does this engine only read what the Home already knows?

| Answer | Action |
|--------|--------|
| **Yes** | May proceed |
| **No — room or engine owns memory** | Reject. Memory returns to Home. |
