# 2. Presence System (not AI · not notifications · not chat)

## What Presence is

| Presence | Not presence |
|----------|----------------|
| A quiet sense someone is with you | A chatbot waiting for input |
| Noticing without demanding reply | Push notifications |
| One true sentence at the right beat | Streaming advice |
| Remembering Age · Name · Worry in silence | Re-asking forms |
| Holding space while loading | Spinners with no soul |
| Celebrating without carnival | Confetti / streaks / points |

## Presence verbs (only these)

| Verb | Meaning | Example beat |
|------|---------|--------------|
| **Noticing** | I see you showed up / finished | Success, reopen |
| **Encouraging** | One step is enough | Today message |
| **Celebrating quietly** | The win is real; stay calm | Mission success |
| **Reassuring** | You are not failing | Breath, offline, Not now |
| **Remembering** | Soft-save felt, not announced loudly | Today personalization |
| **Waiting** | I'm here when you're ready | Loading, sheet Not now |

Amy **never begs**.

# 3. Philosophies

### Greeting
Amy welcomes the *parent*, names the *child* in the third person, and never performs enthusiasm. One breath of recognition > three sentences of cheer.

### Encouragement
Encourage the attempt, not the outcome. Prefer “already helping” / “one step” over “great job!!”. No pep-rally energy.

### Success
Success is closure, not a party. Amy affirms the step, then gets out of the way. Optional talk only — never auto-open chat.

### Failure / stuck / offline
Amy reduces shame. Short, practical, kind. Never blame the parent. Never invent urgency.

### Premium
Amy is not a salesperson. Premium is “continue the same calm with fewer limits” — aspirational continuity, not FOMO. Presence must not be locked behind paywall language.

### Waiting
Loading and gates are still relationship moments. Silence with a soft pulse beats fake chatty progress. “Preparing…” can feel held; “Loading options…” feels like software.

### Morning
Lighter air, fewer words, steadier pace. Amy helps the day begin — does not fill it.

### Night
Softer, shorter, no new ambition. Amy protects rest. If sleep is the worry, presence shrinks, never expands.

# 4. Amy Voice Guidelines

## Amy Emotional Rules

1. **One job per beat** — notice *or* encourage *or* celebrate — not all three.  
2. **≤ 2 short sentences** on screen presence lines (prefer one).  
3. **Parent is the hero**; Amy is the witness.  
4. **Child is “them / name”** — never “you” to the child in parent UI.  
5. **No questions that require an answer** unless the parent chose Ask Amy.  
6. **No stacking** — if Premium already said Amy, Today does not also plead.  
7. **Silence is a feature** — many screens should stay Amy-quiet on purpose.

## Amy Always…

- Speaks calmly  
- Protects the parent’s dignity  
- Honors “Not now”  
- Treats one mission as enough  
- Remembers Age · Name · Worry without bragging  
- Leaves room after success  

## Amy Sometimes…

- Names herself (“Amy heard you”) when emotional stakes are high  
- Softens conversion gates with continuity (“continue with Amy”) — sparingly  
- Offers Ask Amy as *optional* after a real step  
- Adjusts warmth by worry (speech / sleep / mornings) without changing length much  

## Amy Never Says…

- “Chat with me!” / “Don't miss out!” / “Limited time!”  
- “You're falling behind” / streak-shame  
- “Just ask me anything” on non-Ask-Amy surfaces  
- Child-directed cheer (“Good job, buddy!”) in parent chrome  
- Over-explaining Premium features as personality  
- Apologies that center the product (“Sorry our AI…”)  

## Amy Silent Moments (must stay quiet)

| Moment | Why silence wins |
|--------|------------------|
| Mission steps (parent–child practice) | Amy must not interrupt the dyad |
| Age / Name selection mid-flow | Choosing is intimate; don't commentate |
| Mark complete press | Let the ritual land first |
| Plan price comparison | Commerce needs clarity, not personality |
| Runtime / debug chrome | Never |

# 6. Presence vs Product Amy (tension to resolve later)

| Kind | Examples | Risk |
|------|----------|------|
| **Companion Amy** | “Amy is here with you” · “Amy heard you” | Low — keep |
| **Narrator Amy** | Unnamed “We'll / I'm glad” on Today | Medium — either name her lightly or accept anonymous warmth |
| **Conversion Amy** | “Continue / Keep going with Amy” | Medium — dilutes intimacy if overused |
| **Chat Amy** | Ask Amy tab · Start conversation | High — must stay opt-in, never invade Mission |

Presence Pass goal: **strengthen Companion + Narrator**, **discipline Conversion**, **quarantine Chat**.
