# AmyNest Founder Translation Law v2

**Status:** BINDING — overrides every future visual implementation  
**Mode:** Translation only — **not redesign**  
**Supersedes for method:** ad-hoc polish, opacity “Nest-ification,” and prior Founder Rule notes that conflict with this law  
**Companions (unchanged authority):** Design Constitution · Visual Constitution · Room Architecture  
**Earlier note:** [`FOUNDER_TRANSLATION_RULE.md`](./FOUNDER_TRANSLATION_RULE.md) remains useful detail; **this law wins** on conflict.

---

## Preamble

AmyNest is **not** being redesigned.

AmyNest is being **translated**.

Translation means:

| Same | Expressed as |
|------|----------------|
| The same product | Nest Presence Constitution |
| The same features | Nest Presence Constitution |
| The same routes | Nest Presence Constitution |
| The same architecture | Nest Presence Constitution |
| The same capabilities | Nest Presence Constitution |

as if they had **always** belonged to Nest Presence.

---

## Order of decisions (absolute)

1. **DELETE**
2. **MERGE**
3. **WHISPER**
4. **EMPHASIZE**

Never optimize before deleting.

Never restyle clutter. Remove it, then merge what remains, then whisper what must stay quiet, then emphasize the one thing the room is for.

---

## Functional exits — may NEVER disappear

These may become **whispers**.  
They may **never** become impossible.

| Exit | Typical destination (existing) | Threshold today |
|------|--------------------------------|-----------------|
| **Begin** | Web start / Front Door (`/front-door` when Nest path on) | Bloom primary |
| **Sign In** | `/sign-in` | Nav whisper |
| **Get the App** | `/get-app` | Footer whisper |
| **Privacy** | `/privacy` | Footer whisper |
| **Terms** | `/terms` | Footer whisper |
| **Contact** | `/support` *(product label: Support)* | Footer whisper |
| **Restore** | Existing restore / purchase restore surface (e.g. Premium / pricing — **not invented on Threshold**) | N/A on Landing historically — must survive in rooms that already offer it |

If a room already exposes an exit, translation may only demote it to whisper — never remove the path.

---

## Visual exits — may disappear completely

These are **not** functionality. Delete freely.

- Eyebrows  
- Decorative cards  
- Duplicate labels  
- Repeated reassurance  
- Marketing sections  
- Feature catalogues  
- Comparison tables  
- Visual dividers  
- Multiple equal CTAs  

---

## Tired-parent test

For every visible element ask:

> Does this help a tired parent?

If not — **remove it.**

---

## Calm, not emptiness

Do **not** replace clutter with empty space.

Replace clutter with **calm**.

Calm is composition, breath, one emotional answer, and inevitable action — not a blank void that feels broken.

---

## One emotional question per room

| Room | Question |
|------|----------|
| **Threshold** | Can I trust Amy? |
| **Living Room** | What matters today? |
| **Practice Room** | What do I do now? |
| **Study** | Am I being understood? |
| **Hearing Room** | Can Amy help me immediately? |
| **Continuity Room** | Should I stay? |
| **Child's Room** | What can my child discover? |

If a room answers **two** questions, it has **failed**.

*(Vestibule / Keep and other Room Architecture rooms inherit the same law: one question each; name from Room Architecture.)*
