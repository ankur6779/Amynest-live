## 1. Mission

Parent Hub deepens life when Today Home’s next right thing is not enough.

| Surface | Owns |
|---|---|
| **Today Home** | Action — what to do today; Begin |
| **Parent Hub** | Understanding, help, care, and presence beyond one action |

Hub must **never** compete with Home.  
Hub must **never** be a feature mall.  
Hub must increase trust, retention, and subscription by selling **relief · confidence · time · consistency · understanding** — never access.

---

## 2. Product Truth

**Previous truth:** Parent Hub is a feature mall with a journey paywall.  
**Founder truth:** Parent Hub is four human intentions.

Parents never think “Speech Coach” or “Learning Zone.”  
They think: I need help · I want to understand · I need to care · I want a moment.

**Brutal line (approved):**  
Today Home answers “what should I do?”  
Hub must never answer only “what else can you browse?”

---

## 3. Four Rooms

| Room | Parent says | Single purpose |
|---|---|---|
| **Help** | “I need help.” | Unstick a stuck parent |
| **Understand** | “I want to understand.” | See the child more clearly |
| **Care** | “I need to care for them.” | Tend body, rhythm, feeding, health |
| **Moments** | “I want a moment with them.” | Share one human presence |

**Founder locks:**

- Exactly **four** rooms — no fifth destination  
- **Steady** is **tone of every room**, not a room  
- **Birth Sky** ∈ **Understand**  
- **Gamification** permanently forbidden on Parent Hub  
- Every feature ∈ **exactly one** room (or removed from Hub)

### Age gravity

| Cohort | Default gravity |
|---|---|
| 0–24 months | **Care** expands (Hub may open into Care) |
| 2–6 years | Moments + Help common; Care = food/health |
| 6+ | Understand + Help (school/PTM); Moments selective |

### Feature → room (binding)

**Help:** Ask Amy · Emotional Support · Speech Coach · PTM Prep · Life Skills only if “help me teach this”

**Understand:** Guidance (merge Daily Tips + New Parent Tips + Articles + Infant Amy Suggests) · Infant cues/coaching · Milestone **meaning** · Curiosity library · Birth Sky · quiet learning status (no XP) · at most **one** Grow-skills door (collapse Math/Abacus/Phonics/Spelling/Study/Olympiad)

**Care:** Infant cry/sleep/feeding/diaper/growth **measurements**/health/vax/doctor/sounds/weekly focus/co-parent · Infant parent wellbeing (Steady tone) · Nutrition · Health Lab

**Moments:** One Presence (collapse Activities nest + Origami + Art + Audio + Infant activities) · One Story · One Make (worksheets/coloring/fun sheets) · Talking Amy · Discovery Worlds · Event Prep

**Shell / bridge (not rooms):** Child selector · Hub Journey/Path (must not rival Home NRT) · quiet link to Today Home

## 4. Emotional purpose of each room

| Room | Arrive feeling | First seen (≤3s) | Leave holding | Never first |
|---|---|---|---|---|
| **Help** | Stuck · scared · ashamed | “What’s hard right now?” or one clear door | One next try / answered fear | Feature grid · points |
| **Understand** | Curious · uncertain | One Guidance card (+ optional Birth Sky) | One clearer sentence about the child | Tip trilogy · XP |
| **Care** | Exhausted · responsible | Next care act for body/rhythm | Care done or planned | Stories mall · games |
| **Moments** | Wanting connection | “Ten minutes with {name}” | Shared moment started/done | Curriculum warehouse · rewards |

**Steady tone everywhere:** calm · non-judging · no score · no FOMO · no unlock · no guilt · sanctuary materials consistent with Home.

If they leave having only browsed → the room failed.

## 5. Entry Law

> Today Home always wins when action is enough.  
> Parent Hub opens only when Help / Understand / Care / Moments is needed beyond that action.

### Immutable routing rules

| # | Rule |
|---|---|
| R1 | One completable action today → **Today Home only** |
| R2 | Help/Understand/Care/Moments beyond that → **Hub → that room** |
| R3 | Never open Hub as default “explore” after Home |
| R4 | Tab may open Hub — first frame is **intention**, not mall |
| R5 | Deep links open a **room**, never a catalogue |
| R6 | Path may surface Hub only for understanding/care/presence — never “generate routine” |
| R7 | Browse / boredom / “what’s new” / gamification = **forbidden entry reasons** |
| R8 | Ambiguous action+understanding → **split** (Home action first) |
| R9 | Infant body loops may open **Care** directly — still not a mall |
| R10 | “I’m just browsing” → **do not invite Hub** |

### State → destination (canonical examples)

| State | Destination |
|---|---|
| Don’t know what to do today | **Today Home** |
| Begin / continue plan | **Today Home → Begin** |
| Refusing bedtime / what do I say / speech worry / PTM / guilt | **Help** |
| Child is changing / why / Birth Sky mood | **Understand** |
| Baby not sleeping / feed / sick / meals | **Care** |
| Ten free minutes / rainy afternoon together | **Moments** |
| Just browsing / points / dashboard / forecast-as-peer | **Do not open Hub** |
| Post-Discovery first open | **Today Home** first |

**Automatic non-entry when:** NRT+Begin sufficient · mid-routine execution · entry reason ∈ {browse, points, dashboard, what’s new} · `resolveHomeHubBoundary` → `today-home` or `neither`.

## 6. Exit Law

**Never dead ends.**

| Exit | Goes to |
|---|---|
| Done for now | **Today Home** |
| Begin this | Routine / NRT execution (**Home-owned**) |
| Ask more | Ask Amy (from Help/Understand) |
| Another need | Switch room by **intention**, not tile grid |
| Infant Care loop | Continue Care or Home |

| From | Primary exit | Avoid |
|---|---|---|
| Help | Today Home (NRT intact) | Learning mall dump |
| Understand | Today Home (sharpen tomorrow’s NRT) | Paywall as last memory |
| Care | Today Home or continue Care | Gaming |
| Moments | Today Home or gentle Done | Endless related modules |

Smart-back respects entry; when Hub opened from Home → return Home.

## 8. Free vs Premium philosophy

AmyNest never sells access.  
AmyNest sells relief · confidence · time · consistency · understanding.

| Room | Always free | Premium after trust |
|---|---|---|
| **Help** | Emotional · PTM in season · first ask / first speech taste | Ongoing Help / Speech continuity |
| **Understand** | First Guidance sentence · Birth Sky entry · quiet status | Depth / meaning continuity |
| **Care** | Core infant care loops · first Nutrition orientation · wellbeing micro-check | Plans · Nutrition continuity · Health Lab **after** Care trust |
| **Moments** | First presence offer · fair sample | Library depth after joy |

**Home NRT + Begin:** free forever.  
**Never:** Hub as sales landing · gamified unlock · paywall before first crisis help.

**Subscription intent rank:** Care → Help → Understand → Moments.

**Current systems to respect (don’t redesign in constitution phase):** Hub Journey (3 free days / 7-day calendar soft-lock) · feature-usage quotas · content caps · entitlements · RevenueCat via existing paywall · activation defer to first routine · Emotional/PTM journey-exempt.
