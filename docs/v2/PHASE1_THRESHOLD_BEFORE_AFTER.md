## Apple review

**Would ship the composition?** Conditional yes for an internal Threshold dogfood.

**What disappeared:** The warehouse. Badges. Stores. Equal Soft Plates. Second and third CTAs.

**What still nags:** “AmyNest AI” reads product, not place. Float may still feel character-demo. Wordmark should never compete — currently whisper, good.

**Verdict:** Silence earned by deletion. This is the first Landing that could sit in the same Home as Today without lying.

---

## Headspace review

**Would ship the arrival?** Yes for calm entry.

**What became quieter:** Entire below-fold product education. Trust became one breath. Nav stopped selling the app.

**What still nags:** After Begin, Vestibule must not re-awaken anxiety. Threshold success can be undone in the next room.

**Verdict:** Exhale lands. Parent is held, not processed.

---

## Airbnb review

**Would ship the porch?** Yes — human door language.

**What feels more human:** “Begin” instead of “Try on Web.” Amy without feature stack. “It's safe to begin.”

**What still nags:** Specificity of place vs category claim (“One parenting companion”) — acceptable for Threshold; Vestibule can deepen the story.

**Verdict:** Feels like entering a home, not installing a channel.

---

## Linear review

**Would ship the chrome?** Yes — unnecessary chrome died.

**What died:** Catalogue modules, peer CTAs, footer sitemap energy, Soft Plate democracy.

**What still nags:** File still contains legacy SaaS path (correct under flag). Don’t let Nest path regress by “whispering” modules back.

**Verdict:** One primary. Clear hierarchy. No visual democracy.
