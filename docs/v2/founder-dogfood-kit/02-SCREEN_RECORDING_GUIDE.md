# 2. Screen Recording Guide

Record the **full guest happy path** in one take when possible.  
Filename: `amynest-v2-dogfood-{name}-{android|ios|desktop}-{YYYYMMDD}.{ext}`

---

## Android

### Built-in (most phones)

1. Swipe down notification shade → **Screen record** (may be under Quick Settings edit).
2. Start recording → open AmyNest → run happy path → stop.
3. File lands in Gallery / Files → Movies / Screen recordings.
4. Share via Drive / WhatsApp / AirDrop-equivalent to founder folder.

### If no Screen record tile

- **Samsung:** Settings → Advanced features → Screenshots and screen recorder  
- **Pixel:** hold Power → Screen record  
- Or use **AZ Screen Recorder** / **Mobizen** (mic optional)

### Tips

- Record in portrait.
- Microphone **off** unless you want think-aloud (preferred: think-aloud **on** for founders).
- Hide notification content if privacy matters; dogfood build only.

---

## iPhone

1. Settings → Control Center → add **Screen Recording**.
2. Open Control Center → long-press Screen Recording → Microphone **On** for think-aloud.
3. Tap Record → wait 3s → open AmyNest → run path → Control Center → stop.
4. Video saves to **Photos**. Share to founder Drive / AirDrop.

### Tips

- Use Low Power Mode off during record (drops frames less).
- Do not switch to other apps mid-path.
- If Face ID / passcode overlays appear, note them; continue.

---

## Desktop (browser dogfood)

### macOS QuickTime

1. QuickTime Player → File → New Screen Recording.
2. Select browser window (Chrome/Safari) only.
3. Optional mic for think-aloud.
4. Run path → Stop → save file.

### macOS screenshot toolbar

`⇧⌘5` → Record Selected Portion → select browser → Record.

### Windows

- **Win + G** → Xbox Game Bar → Capture → Record  
- Or **Win + Alt + R**  
- Or OBS (browser window source)

### Tips

- Use a clean profile / Incognito if asked (fresh guest).
- Zoom 100%; window tall enough to show bottom nav.
- Show cursor; avoid multi-monitor capture unless needed.

---

## What to capture (checklist)

- [ ] App open / cold start  
- [ ] Full Front Door through Continue to Today  
- [ ] Mission start → complete → Back to Today  
- [ ] Ask Amy CTA or tab once (sheet OK)  
- [ ] Premium CTA once  
- [ ] Kill + reopen (mobile) or hard refresh only if instructed  
- [ ] Stop within ~20 minutes  

## What not to capture

- Passwords / OTP full codes (pause or blur)  
- Unrelated personal photos / notifications  
- Production purchases  

## Delivery

Upload to the founder-shared folder the same day.  
Attach file name on Observation Sheet + any Bug Reports.
