## Column guide

| Column | Capture |
|--------|---------|
| **Timestamp** | `mm:ss` from recording start |
| **Screen** | Front Door / Today / Mission / Success / Premium gate / Account sheet / Sign up / Other |
| **What happened** | Factual — taps, navigations, outcomes |
| **Hesitation** | Pause, re-read, hover, back-and-forth (Y/N + brief) |
| **Confusion** | Wrong expectation spoken or visible (quote if think-aloud) |
| **Positive moment** | Smile, “nice”, speed, clarity |
| **Negative moment** | Frustration, dead end, distrust |
| **Recommended action** | Observe / Fix P0 / Fix P1 / Copy tweak / Ignore for Alpha / Ask in retro |
| **Severity** | none / P0 / P1 / P2 |
