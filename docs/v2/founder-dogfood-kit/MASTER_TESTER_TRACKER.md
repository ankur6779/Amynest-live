## Column definitions

| Column | How to fill |
|--------|-------------|
| **Tester ID** | `T01`… stable ID (not real name in shared sheets if privacy matters) |
| **Parent age** | Approximate band OK (e.g. 28–32) |
| **Child age** | Years or Front Door band (e.g. 3–5) |
| **Android / iPhone** | Primary device used for the recorded path |
| **Completed?** | Y if Front Door → Today → Mission path finished end-to-end |
| **Mission completed?** | Y if Mark complete → success seen |
| **Premium opened?** | Y if Premium CTA opened (gate OK) |
| **Account created?** | Y if they created / signed in during session |
| **Would Pay?** | Yes / Maybe / No |
| **Score (/10)** | Overall session quality (founder or tester gut) |
| **P0 / P1 / P2** | Count of bugs filed for that tester |
| **Notes** | Short — link session review / recording filename |
