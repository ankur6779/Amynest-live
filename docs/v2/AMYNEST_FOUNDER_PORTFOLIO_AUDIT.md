AmyNest now has a **real front door** and a set of **manufactured openings** that feel like the same home.

### One sentence truth

> AmyNest is a calm parenting home **at the door**, and a federation of feature products **inside**.

### Founder test — never left the same home?

**At the door: YES.**  
**Through the house: NO.**

Same light, photography, materials, typography, emotional voice, philosophy, premium calm, and trust **inherit on manufactured first frames**.  
They **break** when parents deepen into Speech neon sessions, Nutrition SaaS tabs, Health Lab game body, Grow leave apps, Birth Sky Astro wing, `/assistant` desk, Curiosity storefront, Discovery Worlds XP, Help/Care/Understand peer catalogues, or flag-OFF legacy mall.

### Product test — why / what / today / next / leave?

Manufactured opens increasingly answer these five questions.  
Many deepen paths still reopen **feature catalogues**, **SKU nests**, **mode desks**, or **game OS**.

### Premium test

Quiet living opens teach **continuity / support / confidence / time saved**.  
Leave-paths still teach **unlock / marketplace / upgrade / subscription pressure**.

### Trust test

A tired parent can trust the **door**.  
They cannot yet trust **every module** — SaaS, AI demo, dashboard, marketplace, game, astrology wing, and “another company” still appear after calm opens.
