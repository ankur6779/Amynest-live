# Board 1 — Opening AmyNest

### Hero visual
A deep ink atmosphere.  
One warm living presence rising at center — Amy as light before language.  
The board feels like a quiet room at first open: empty, intentional, alive.

### Visual hierarchy
1. Living light / Amy presence  
2. Atmospheric depth around it  
3. Absolute silence in the periphery  

Nothing else earns rank.

### Eye path
Enter center → rest on the living light → remain.  
No secondary destinations. The eye is not invited to wander.

### Negative space
Majority of the board is emptiness.  
Emptiness is the product feeling.  
Corners stay dark and unused on purpose.

### Typography hierarchy
Almost none at first beat.  
If language appears later in the moment, it is secondary to presence:  
one short line of arrival, never a headline stack.

### Illustration direction
Abstract luminous presence over mascot merchandise.  
Amy should feel spiritual-tech and warm, not cartoon-store.

### Photography direction
No lifestyle collage.  
If any photographic texture exists, it is atmospheric only — soft home dusk, not people stock smiles.

### Material usage
Velvet dark field.  
Vapor glass glow.  
Warm inner light core.  
No hard plastic surfaces.

### Animation intention
Slow inhale of light.  
Presence settles.  
Hold.  
No bounce. No particle fireworks.

### Trust trigger
The product does not ask.  
Composure proves safety.

### Conversion trigger
Emotional entry.  
Continue because the room feels right.

### First 3 seconds — parent should FEEL
**“I can breathe here.”**

# Production Acceptance Gate

Before visual implementation begins from these boards, each board must still answer yes:

1. Can it be felt in 3 seconds without explanation?  
2. Is there only one subject?  
3. Does negative space outrank decoration?  
4. Does it advance Trust or Conversion without force?  
5. Does it serve the promise: **next right thing for this child, today**?

If any board fails, do not implement it.
