# I. What AmyNest is

AmyNest is not an application.  
AmyNest is a **Home**.

Every destination is a **Room**.  
The identity of the air is **Nest Presence**.

The parent does not open apps. They cross thresholds.  
Rooms share the same air, the same hour of light, the same hush.  
Nothing in the Home shouts a different brand of weather.

---

# II. The Contract (core)

The Home is permanent.

Frameworks are temporary.

Every future engine,  
module,  
feature,  
AI capability,  
or SDK  
must enter the Home  
through an existing room.

No feature creates a new visual language.

No feature creates a second navigation.

No feature creates a second shell.

No feature creates a second atmosphere.

Every capability is a resident,  
never a visitor.

Rooms own emotion.

Engines own execution.

The Home owns continuity.

---

# III. Resident Law

Every new capability must become a **better resident**, not a **bigger building**.

If a feature requires its own identity, it does not belong inside AmyNest.  
It belongs outside.

AmyNest grows by **deepening rooms**, never by adding products.

| Pass | Fail |
|------|------|
| The room feels more itself | The Home feels like a suite of products |
| No competing brand / chrome / name | Feature needs its own logo, nav, splash, or product voice |
| Lands in an existing room’s job | Invents a product, destination, or peer surface |

---

# IV. One Memory Law

There is only **one Amy**.

Coach remembers. Mission remembers. Ask Amy remembers. Child remembers. Premium remembers.

**No room owns memory. The Home owns memory.**

Engines only **read** what the Home already knows.

| Forbidden | Allowed |
|-----------|---------|
| Engine or room memory silos | Engines caching reads (Home remains truth) |
| A second Amy per surface | Writes that **update Home memory** |
| Parent re-introducing the child to Amy | Room presentation of what Home already knows |

---

# V. Home API Law

The Home is the **primary API**.

Frameworks are adapters.  
AI providers are adapters.  
Billing providers are adapters.  
SDKs are adapters.

**Nothing outside the Home may define the user experience.**

```
Parent experience
       ↑
   THE HOME  ← primary API
       ↑
   adapters  ← frameworks · AI · billing · SDKs
```

Invert this stack → you have broken the soul.

---

# VI. Ownership triad

| Owner | Owns | Does not own |
|-------|------|--------------|
| **Rooms** | Emotion | Execution; visual languages; memory |
| **Engines** | Execution (reading Home memory) | Chrome; second shells; memory silos; UX definition |
| **Home** | Continuity — one shell, one nav, one atmosphere, one memory, primary API | Feature catalogues; visitor products |

---

# VII. The rooms (emotional index — permanent)

These are the **only** rooms. Do not invent a new room without Founder-equivalent reopen of this Contract.  
Deepen these. Do not add products beside them.

| Room | Emotional job (soul) |
|------|----------------------|
| **The Threshold** | Arrive. Breathe. Decide to enter. |
| **The Vestibule** | Be welcomed. Be known lightly. |
| **The Keep** | Softly lock what must be kept. |
| **The Living Room** | Meet the day with Amy. |
| **The Practice Room** | Keep one short ritual. Leave relieved. |
| **The Study** | Be seen for the longer path. |
| **The Hearing Room** | Speak. Be answered. Be held. |
| **The Continuity Room** | Choose to stay. |
| **The Child’s Room** | The child’s small world — only when alive. |

Former page-names (dashboard, signup, ask amy, coach, mission, premium…) are **forgotten labels**. Use room names when deciding where work lives.

**Feeling law (never violate):**

- Same Nest air across rooms — no different brand of weather  
- A room is defined by what it holds — and by how much it refuses to hold  
- Loading is calm prepare / reveal — never generator theatre, never “Meet AI” product splash as Nest language  
- Commerce lives in Continuity — not inside care threads  

Longer feeling briefs may exist elsewhere for craft; if they conflict with this index, **this index wins** for soul.

---

# VIII. Nest Presence (atmosphere — locked)

Nest Presence is the Home’s air.

| Permanent | Forbidden |
|-----------|-----------|
| One Nest visual / atmospheric language already completed for Nest shells | A new visual language for a feature or engine |
| Soft, calm, continuous Nest hour | SaaS dashboard DNA, chatbot theatre, checklist DNA as Nest care |
| Craft tokens already owned by Nest Presence | Rewriting Constitution / Nest CSS as “improvement” without Contract reopen |

**Design manufacturing is COMPLETE.** Further premium on Nest-owned shells is not available by inventing CSS. Further soul is preserved by **framework residency** (Home primary), not by redesigning rooms.

If you did not build Nest Presence: **do not invent a second one**. Consume what Nest already is. Do not ship visitor chrome.

---

# IX. Entry law (ship gate)

A capability may ship only if **all** are true:

1. Enters through an **existing room** in §VII  
2. No new visual language  
3. No second navigation  
4. No second shell  
5. No second atmosphere  
6. Resident of that room — not visitor app / splash / peer Home  
7. **Better resident** — deepens the room; no own identity (§III)  
8. **One Amy** — reads/writes Home memory only (§IV)  
9. **Home defines UX** — outside is adapter only (§V)  

If any fails → **rejected at the door**.  
If it needs its own identity → **belongs outside** AmyNest — not Nested by skin.

# XI. How an engineer continues (operating manual)

When you receive work:

1. **Name the room** in §VII. If none fits, stop — do not invent a product.  
2. Ask: better resident or bigger building? (§III)  
3. Ask: still one Amy? (§IV)  
4. Ask: does Home define UX, or is an SDK/provider defining it? (§V)  
5. Implement as **adapter under Home** — Nest atmosphere, Nest shell, Nest nav.  
6. Never open a second Home to “ship faster.”  

**Platform V3** (when approved) exists only to **evict visitors** and **seat residents**. It does not redesign rooms, rewrite Nest CSS, or edit this Contract’s soul.

Debt inventories and phase plans are temporary maps. This Contract is the territory.
