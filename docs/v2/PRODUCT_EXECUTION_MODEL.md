# AmyNest Product Execution Model

**Phase:** PRODUCT EXECUTION MODEL  
**Status:** LOCKED  
**Audience:** Design · Engineering · AI · Growth · Support · QA

---

## Locked Product Promise

AmyNest helps parents know  
their child's  
**next right thing**  
**today.**

Everything exists only to make this promise true.

---

## Mission

Describe how AmyNest fulfills that promise.

Not through features.  
Through **one execution loop**.

---

## The One Execution Loop

```text
Understand
    ↓
Decide
    ↓
Execute
    ↓
Remember
    ↓
Improve
    ↓
Understand again
```

Repeat forever.

This is the only product engine.  
Every module must enter this loop.  
No module may exist as a destination outside it.

---

## Stage 1 — UNDERSTAND

### Responsibility

Collect only what is required to know:

> For **this child**, given **today**, what is true right now?

### Information that enters

| Input | Responsibility |
|---|---|
| **Child** | Who we are deciding for |
| **Age** | What is developmentally possible and relevant |
| **History** | What has already been tried, worked, failed, or skipped |
| **Context** | School day, weekend, caregiver constraints, goals in play |
| **Family** | Parent capacity, co-parenting, household reality |
| **Environment** | Location, weather, outdoor suitability, local daily life |
| **Today's state** | Mood, sleep, energy, unfinished steps, current moment |

### What Understand must never do

- Entertain
- Upsell
- Open a module menu
- Ask the parent to browse destinations

Understand exists only to feed Decide.

---

## Stage 2 — DECIDE

### Responsibility

Choose **one** answer:

> Today's next right thing for this child is: **____.**

### Decision responsibility

Amy decides by weighing:

1. **Who the child is** — age and developmental fit  
2. **What today allows** — school, environment, family capacity  
3. **What history says** — what worked, what was skipped, what stalled  
4. **What is unfinished** — today's open chain of actions  
5. **What matters most now** — the highest-value next step, not the full catalog  

### Decision output

One clear next right thing.

Not ten options.  
Not a feature tour.  
Not “explore the hub.”

### What Decide must never do

- Replace itself with a module picker  
- Hide behind “AI said so” without a usable next step  
- Offer everything equally  

Decide exists only to create a single executable truth for today.

---

## Stage 3 — EXECUTE

### Responsibility

Help the parent complete today's next right thing.

### Execution rule

Every module becomes an **execution surface**.

Never a destination.

| If today's next right thing is… | Execution surface |
|---|---|
| Finish the morning sequence | Mission / Routine / School Morning Flow |
| Handle a parenting stuck point | Coach |
| Practice speech for 5 minutes | Speech |
| Serve the right meal / tiffin | Nutrition |
| Settle sleep / wake window | Sleep |
| Do a short play-learning block | Games / Discovery / Learning |
| Reset body / calm / movement | Health Lab |

### Execution contract

1. Show the next right thing  
2. Make completion obvious  
3. Allow Complete / Skip / Delay  
4. Return the parent to today's truth after action  

### What Execute must never do

- Turn into open-ended browsing  
- Keep the parent inside a world with no return to today's next step  
- Compete with Decide for attention  

Execute exists only to make the decision real.

---

## Stage 4 — REMEMBER

### Responsibility

Store reality — not content preference theater.

### What Amy stores

| Memory | Meaning |
|---|---|
| **Reality** | What actually happened today |
| **Completion** | What was done |
| **Skip** | What was bypassed |
| **Delay** | What slipped in time |
| **Patterns** | What repeats across days |
| **Confidence** | How reliable today's signal was |

### What Remember must never do

- Store vanity metrics as truth  
- Confuse entertainment activity with parenting progress  
- Forget the outcome of today's next right thing  

Remember exists only to make Improve possible.

---

## Stage 5 — IMPROVE

### Responsibility

Make tomorrow's next right thing better than today's.

### How tomorrow becomes better

- Completed steps raise confidence in similar recommendations  
- Skipped steps reduce false urgency next time  
- Delayed steps reshape timing and load  
- Patterns reveal what this family can actually sustain  
- Environment and school context keep recommendations realistic  

### Improve output

A sharper Understand for the next loop.

### What Improve must never do

- Reset to generic advice every morning  
- Punish the parent  
- Optimize for engagement instead of fit  

Improve exists only so the loop compounds.

- **CORE** — without it, the promise cannot be kept  
- **SUPPORTING** — makes the promise more accurate or doable  
- **OPTIONAL** — may help execute, but is not required  
- **DISTRACTION** — can be used without answering today's next right thing  
- **PLATFORM** — business/account plumbing around the product

## The AmyNest Flywheel

```text
Understand
    ↓
Decide
    ↓
Execute
    ↓
Remember
    ↓
Better Tomorrow
    ↓
Understand again
```

### Flywheel meaning

1. **Understand** gathers today's truth for this child.  
2. **Decide** names one next right thing.  
3. **Execute** helps the parent complete it.  
4. **Remember** stores what really happened.  
5. **Better Tomorrow** uses that reality to improve the next decision.  
6. The loop returns to **Understand** — sharper than before.

### Flywheel test

A feature is inside AmyNest only if it strengthens at least one stage:

- better understanding  
- clearer decision  
- easier execution  
- truer memory  
- better tomorrow  

If it does none of these, it is outside the product.
