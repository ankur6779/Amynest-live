## Conflict resolution

**Always walk up the hierarchy.** The higher document wins. Stop when resolved.

| Conflict | Winner | Why |
|----------|--------|-----|
| Platform Architecture vs Immutable Laws | **Immutable Laws** | Platform is temporary program |
| Platform Architecture vs Design Constitution | **Design Constitution** | Platform may not invent craft or second language |
| Platform Architecture vs Visual Constitution | **Visual Constitution** | Soul over adapter plan |
| Platform Architecture vs Home Contract | **Home Contract** | Residents/entry/Home narrative over phase plan |
| Design Constitution vs Visual Constitution | **Neither invents** — Design = system, Visual = soul; if token contradicts soul climate, **Visual soul intent** wins and Design must be amended by Founder to match |
| Design Constitution vs Immutable Laws | **Immutable Laws** | Craft cannot legalize a second Home or fifth material family against L09/L11 |
| Visual Constitution vs Immutable Laws | **Immutable Laws** | |
| Home Contract vs Immutable Laws | **Immutable Laws** | Contract expands; laws bind |
| Room Architecture vs Home Contract room jobs | **Home Contract / Immutable L05** jobs | Longer prose yields to fixed jobs |
| Implementation Law vs Room Architecture | **Room Architecture** for feeling; **Implementation Law** for process sequence | Process cannot rewrite emotional job |
| Implementation Law vs Immutable Laws | **Immutable Laws** | |
| Law Index vs any binding doc | **Binding doc** | Index is not law |
| Engineering (code) vs any Canon layer | **Canon layer** | Code is the lowest layer |
| Founder Oath vs Immutable Laws | **Immutable Laws** | Oath cannot create exemptions |
| Debt register “recommendation” vs Canon | **Canon** | |

### Worked examples

**Example A — Design Constitution vs Platform Architecture**  
Platform wants a phase that ships a new button family for “coach generator UX.”  
→ **Design Constitution wins** (and Immutable L11 / L13). Platform must adapt under Nest materials or wait for Founder craft amendment.

**Example B — Platform vs Immutable Laws**  
Platform proposes a second shell “just for Speech Coach.”  
→ **Immutable Laws win** (L09 Unity · L07 Resident · L15 Entry). Reject.

**Example C — Home Contract vs Design Constitution**  
Contract requires Nest prepare language; Design locks loading to calm opacity pulse, not spinner carnival.  
→ No conflict if both Nest; if Platform/engine brings spinner DNA, **Design + Immutable L16** win over engine habit.

**Example D — “Sole survival document” language in older files**  
If any satellite still calls itself sole supreme, **this Canon + Immutable Laws** supersede that claim. Update satellite on next Founder-approved edit; until then, **Canon hierarchy wins in practice**.
